If you think Linux dating all the way back to 1991 is old, wait'll you hear about AT&T UNIX. This talk is a whirlwind tour of ancient UNIX quirks that existed long before Linus ever started kernel hacking; quirks we've all accepted in the community and have become so inured to working around that we don't even think of them as problems anymore, if we think of them at all. Come learn some history, learn some real-life gotchas and how to avoid them, and some words of wisdom all the greybeard old-timers forgot to give you.
