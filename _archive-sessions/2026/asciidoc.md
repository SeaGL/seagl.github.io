AsciiDoc is a great text tool for documentation from simple notes to books. AsciiDoc is human readable plain text markup.

Since it's plain text, AsciiDoc lends itself to revision control systems. Even WebUI systems like GitHub wiki can support it.

AsciiDoc was created in 2002 as a human readable format for publishing DocBook XML. Via different backend processors, it can be converted to many other formats as well. Plain text, revision control and wikifiable is a trifecta of sysadmin documentation awesomeness.

Important AsciiDoc features:

* human readable plain text markup
* easy learning curve
* many output formats ( HTML, DocBook, man pages, ODF, ePub, PDF, and more )
* widely supported
* ease of revision control
* detailed, complex formatting available when needed
* GPLv2

After attending this session, audience members will be familiar with basic AsciiDoc syntax and exporting to different backend formats. They will also learn advantages and disadvantages of AsciiDoc and Markdown.
